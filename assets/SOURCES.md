`xero-certified-specialist-level-3-badge.png` is the individual certification
badge Xero placed in the certificate it issued to Ryan Duguid. It is the same
file the website publishes at
`assets/credentials/xero-certified-specialist-level-3-badge.png`, byte for byte;
that repository's `assets/credentials/SOURCES.md` records how it is rebuilt from
the certificate and holds the certificate itself. The copy lives here so the
profile README never depends on the website being deployed to show an image.

these repositories.

Keep it at its native square aspect ratio, with `width` and `height` set so the
box is reserved before it loads. Do not recolour, crop, rotate or redraw it, and
do not make it a link on its own: the qualification name and both dates stay
beside it in the README as text, so the image carries no information by itself
and is marked decorative with an empty `alt`.

## Renewal

The certification runs from 1 July 2026 to 1 July 2027. On renewal, replace this
file and refresh the hash above, then update the Background section in
`README.md` and the Credentials line in `llms.txt`. The website repository has
its own list of places to update.
