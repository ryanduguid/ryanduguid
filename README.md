I'm an accountant in Newcastle, Australia. I build open-source controls for Australian accounting work, from payroll timing and Xero exports to Excel models and AI-assisted review.

I use fabricated data in public examples. A qualified professional reviews each result and handles ledger changes or lodgement.

## Selected work

- [xero-trial-balance-export](https://github.com/ryanduguid/xero-trial-balance-export) exports balanced Xero trial balances to CSV for Power BI, Excel and pandas.
- [payday-super-checker](https://github.com/ryanduguid/payday-super-checker) checks fund receipt dates against Payday Super deadlines and prepares exceptions for review.
- [Aus Accounting MCP](https://github.com/ryanduguid/aus-accounting-mcp) runs Australian accounting checks through MCP on the operator's machine.
- [DrDebits](https://github.com/ryanduguid/DrDebits) maps APES 110 and TPB Code guardrails to AI-assisted Australian tax work.
- [Ozzit](https://github.com/ryanduguid/Ozzit) provides 134 native Excel LAMBDA functions for financial modelling and GST arithmetic.
- [Australian Accounting Technology Index](https://github.com/ryanduguid/awesome-australian-accounting-tech) catalogues open-source tools and data for Australian accounting.

[Browse the full project catalogue and worked examples](https://duguid.com.au/).
