# Ryan Duguid: Australian accounting automation

I am an Australian accountant in Newcastle, NSW. I build open-source tools for Xero, Excel and Power Query, payroll, superannuation and AI-assisted accounting.

Provisional Member CA ANZ; SAP S/4HANA certified in FI and CO; Xero L3

## Selected work

- **[payday-super-checker](https://github.com/ryanduguid/payday-super-checker)** - Compliance engine for Australian payday-super deadlines (SGAA 1992 s 18C, in force 1 July 2026) and SG charge exposure estimates.
- **[Ozzit](https://github.com/ryanduguid/Ozzit)** - 130 native Excel LAMBDA functions under a single `oz.` prefix for dynamic-array financial models, with no macros or add-ins.
- **[JohnSpenceOgilvy](https://github.com/ryanduguid/JohnSpenceOgilvy)** *(xero-trial-balance-export)* - Exports balanced Xero trial balances to validated CSV for Power BI, Excel and pandas via OAuth 2.0 and Windows DPAPI.
- **[MaryAddisonHamilton](https://github.com/ryanduguid/MaryAddisonHamilton)** *(australian-accounting-skills)* - Nine Claude Code skills for Australian public-practice accounting workflows (BAS, FBT, Division 7A, STP).
- **[subcontractor-accounting-skills](https://github.com/ryanduguid/subcontractor-accounting-skills)** - Claude Code skills for Australian subcontractor accounting (progress claims, retentions, WIP, fuel tax credits, Coal LSL).
- **[monthly-close-control-plane](https://github.com/ryanduguid/monthly-close-control-plane)** - Review-first controls for trial-balance exports: deterministic integrity, variance and reconciliation exceptions for human review.
- **[RaymondChambers](https://github.com/ryanduguid/RaymondChambers)** *(atobenchmark)* - ATO small business benchmark comparison and industry ratio calculation engine.
- **[DrDebits](https://github.com/ryanduguid/DrDebits)** - Source-linked LLM operating guide and ethics guardrails for Australian accounting, tax and BAS work (TASA 2009 / APES 110).
- **[xero-ai-review-gateway](https://github.com/ryanduguid/xero-ai-review-gateway)** - Fixed-policy, synthetic-data safety boundary for AI-assisted financial reviews.
- **[SirArthurFadden](https://github.com/ryanduguid/SirArthurFadden)** *(au-tax-legislation-corpus)* - Commonwealth tax legislation corpus builder for LLM retrieval and rates indexing.
- **[SirAlexanderFitzgerald](https://github.com/ryanduguid/SirAlexanderFitzgerald)** *(accounting-excel-toolkit)* - Power Query (M) and VBA modules for Australian ledger exports and reconciliations.
- **[release-policy](https://github.com/ryanduguid/release-policy)** - Shared release policy: reusable GitHub Actions workflows and testable release gates (ADR-0001).

## Working method

I check rates, dates and section references against primary sources. Outputs reconcile to inputs, surface exceptions and leave professional judgement and consequential action to appropriately authorised people.

Public examples use synthetic or non-client data. Original projects and contribution forks are identified separately, and forks retain upstream authorship and licence histories. No client data is committed.
