# Ryan Duguid: Australian accounting automation

I am an Australian accountant in Newcastle, NSW. I build open-source tools for Xero, Excel and Power Query, payroll, superannuation and AI-assisted accounting.

Provisional Member CA ANZ; SAP S/4HANA certified in FI and CO; Xero L3

## Selected work

- **[payday-super-checker](https://github.com/ryanduguid/payday-super-checker)** - Experimental CSV review for Australian payday-super deadlines and possible SG-charge exposure. It does not determine legal liability or an ATO assessment.
- **[Ozzit](https://github.com/ryanduguid/Ozzit)** - 130 native Excel LAMBDA functions for dynamic-array financial models, with no macros or add-ins.
- **[xero-trial-balance-export](https://github.com/ryanduguid/xero-trial-balance-export)** - Exports Xero trial balances to CSV only after both movement and year-to-date balances reconcile.
- **[australian-accounting-skills](https://github.com/ryanduguid/australian-accounting-skills)** - Nine Claude Code skills for Australian public-practice accounting workflows.
- **[ato-benchmark-compare](https://github.com/ryanduguid/ato-benchmark-compare)** - Local profit-and-loss comparison against ATO small-business benchmarks, with the working shown.
- **[DrDebits](https://github.com/ryanduguid/DrDebits)** - Source-linked LLM operating guide for Australian accounting, tax and BAS work.

## Working method

I check rates, dates and section references against primary sources. Outputs reconcile to inputs, surface exceptions and leave professional judgement and consequential action to appropriately authorised people.

Public examples use synthetic or non-client data. Original projects and contribution forks are identified separately, and forks retain upstream authorship and licence histories. No client data is committed.
